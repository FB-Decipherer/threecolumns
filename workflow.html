Auto-Gyro · How a GYR-O site is kept

One task, one site, one log

  • Blue — what the site’s owner does: the plain-English prompts typed to Claude.
  • Orange — what Claude does: reads and updates the site’s own log, so nothing depends on the AI remembering.

Four live GYR-O sites, all kept the same way. Each work session starts empty. Everything it needs to pick up where the last one left off lives in one file, a log kept in that site’s own folder, not in the AI’s memory and not in the chat. Each site’s name opens the live page; under it is the repository that holds its source. The prompts are real, and each has a Copy button.

A new site joins as one more lane exactly like these.
